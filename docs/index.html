Быстрый старт

Установка не нужна: распаковали и запустили.

Меня пригласили

  1. Скачайте архив и запустите corsa-mess.exe.
  2. Попросите у друга код комнаты, он выглядит как abcdef-ghijk.
  3. Вставьте код на главной странице и нажмите «Подключиться».
  4. Если комната закрыта, введите пароль, который назвал друг.

Хочу свою комнату

  1. В блоке «Запустить свой сервер» задайте название и пароль.
  2. Нажмите «Запустить сервер» и отправьте друзьям код.
  3. Для друзей из другой сети нажмите «Открыть доступ из интернета».
  4. Если роутер не поддерживает UPnP, используйте Radmin VPN, ZeroTier или Tailscale.

Windows может показать предупреждение SmartScreen: сборка не подписана. «Подробнее» → «Выполнить в любом случае».
