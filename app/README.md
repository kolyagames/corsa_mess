# corsa-mess

Открытый мессенджер для друзей без центральных серверов: чаты, голос, показ экрана, плагины и темы.
Один из участников нажимает «Запустить сервер», остальные подключаются по коду или по адресу.

## Запуск

```bash
npm install
npm start       # приложение
npm test        # проверки сервера, защиты, стикеров и UPnP
```

Нужен Node.js 20+ (проверено на 24). Приложение: Electron, интерфейс на обычном HTML/JS без сборки.

## Как подключаться

- **Код комнаты** вида `abcdef-ghijk` — это IPv4 и порт, записанные буквами. Сервера-посредника нет.
- **В одной сети** достаточно кода из окна «Запустить сервер».
- **Через интернет**: кнопка «Открыть доступ из интернета» просит роутер открыть порт (UPnP) и показывает код с внешним адресом.
  Работает только с паролем сети. Порт закрывается при остановке сервера.
  Если роутер не поддерживает UPnP или у провайдера общий адрес (CGNAT), используйте Radmin VPN, ZeroTier или Tailscale и подключайтесь по адресу из этой сети.

### Это не VPN как Hamachi

corsa-mess соединяет людей внутри приложения (чат, голос, экран). Он не создаёт виртуальный сетевой адаптер и не передаёт
трафик других программ, поэтому игры по «локальной сети» через него не заработают. Для этого поставьте ZeroTier, Tailscale или Radmin VPN.

## Безопасность

| Угроза | Защита |
|---|---|
| Подслушивание | Весь обмен шифруется (TLS, wss). Сертификат создаётся один раз и хранится в папке данных. |
| Подмена сервера | Отпечаток сертификата запоминается при первом входе. Если изменится — соединение блокируется и показывается предупреждение. |
| Чужие в комнате | Пароль сети. Он не передаётся: сервер шлёт случайный вызов, клиент отвечает HMAC от ключа PBKDF2. Подслушанный ответ повторить нельзя. |
| Подбор пароля | После 5 ошибок адрес блокируется на минуту. |
| Перегрузка | Лимиты: 50 участников, 6 соединений с адреса, 20 сообщений в секунду на соединение, тайм-аут рукопожатия, проверка живости. |
| Самозванцы | Другим участникам показывается не настоящий идентификатор, а его хэш. Права владельца привязаны к настоящему. |
| Нежелательные участники | Владелец может исключить и заблокировать. Адрес 127.0.0.1 не банится. |
| Кража IP через картинки | Ссылки только с проверенных сайтов (`shared/allowlist.js`) и политика CSP: редиректы на чужие адреса блокируются. |
| Взлом через интерфейс | Весь чужой текст попадает на страницу как текст. Песочница, изоляция контекста, запрет навигации и новых окон. |
| Подмена команд | Запросы из интерфейса принимаются только от нашей страницы. Входные данные проверяются. |
| Опасные плагины | Свои плагины по умолчанию выключены. Хэш файлов запоминается при включении: любое изменение отключает плагин. Встроенные плагины — часть приложения (`src/builtin`). |
| Поиск комнат в сети | Сервер отвечает на запрос только адресам из своих сетей (и 127.x), не чаще раза в 300 мс на адрес. Сообщает название, замок, число участников и начало отпечатка. |
| Ссылки в сообщениях | Не открываются, а копируются: подставная ссылка не узнает ваш IP. |
| Правка и удаление | Изменить можно только своё сообщение, удалить и закрепить — своё или любое, если вы владелец. Каналы меняет только владелец. |
| Личные сообщения | Сервер пересылает их только отправителю и получателю и не пишет в файл истории. История хранится у собеседников. |
| Файлы | Хранятся у хозяина (`rooms/<порт>-files`), до 25 МБ на файл, 1 ГБ на комнату, 150 МБ за 10 минут на участника. Выдаются только подключённым участникам по их личному ключу. Тип определяется по содержимому: внутри чата показываются только картинки, видео и звук, остальное (в том числе SVG и HTML) — только скачать. Удаление сообщения стирает его файлы. В интерфейс файлы попадают через `corsa://roomfile/…`: главный процесс берёт их у комнаты с проверкой закреплённого сертификата. |
| Перенос плагинов | Из BetterDiscord и Vencord читаются имена включённых плагинов и настройки только нескольких из них (DiscordEffects, CustomRPC, MessageLogger, BlurNSFW, NitroSoundpad, AnonymiseFileNames, VoiceMessages, CallTimer). |
| Глобальные клавиши | Регистрируются только если вы их включили; принимаются сочетания из букв, цифр и F-клавиш. |
| Обновления | Сведения берутся только из релизов kolyagames/corsa_mess на GitHub, архив качается только с адреса загрузок этого репозитория и ставится, только если его SHA-256 совпал с суммой из описания релиза. Устанавливает скрипт PowerShell после выхода приложения (журнал — `%TEMP%\corsa-mess-update.log`). |
| Пароль для автозапуска | Хранится в `secrets.json`, зашифрованным средствами Windows (DPAPI через safeStorage), и только если включено «Сразу открывать свою комнату». |
| Отладочный порт | Запуск с `--remote-debugging-port` и `--inspect` запрещён. |

**Плагин — это код с полным доступом к интерфейсу.** Включайте только те, которым доверяете.

Ограничения: отпечаток при самом первом входе принимается на веру (как в SSH), поэтому для важных комнат сверяйте его с владельцем
другим способом. Блокировка по адресу не поможет, если у человека динамический адрес.

## Плагины и темы

Откройте папки из Настройки → Плагины и Внешний вид. Тема — `.css` файл, плагин — папка с `manifest.json` и `index.js`.
Примеры лежат в `examples/`. Пример плагина добавляет команду `/dice`.

Встроенные плагины (`src/builtin/plugins.js`) сделаны заново по мотивам плагинов BetterDiscord и Vencord, чужой код не копировался.
Кнопка «Перенести из BetterDiscord и Vencord» читает только имена включённых плагинов из их настроек и включает подходящие.

Что может плагин (`start(api)`):

| Метод | Что делает |
|---|---|
| `api.addCommand(имя, fn, описание)` | команда в чате `/имя` |
| `api.on(событие, fn)` | `message`, `edit`, `delete`, `dm`, `member`, `left`, `typing`, `voice`, `connect`, `disconnect` |
| `api.decorate(место, fn)` | свои элементы: `message`, `msgTools`, `reaction`, `member`, `memberHeader`, `profile`, `channel`, `userbar`, `sideTop`, `sideBottom`, `railBottom`, `roomTooltip`, `voiceTile`, `voiceControls`, `composer` |
| `api.intercept(действие, fn)` | `typing` (вернуть false — не слать), `delete` (true — оставить на экране), `activity`, `userbarSub`, `upload` (можно вернуть Promise: сжать файл, сменить имя) |
| `api.addCss`, `api.interval`, `api.cleanup`, `api.storage` | стили, таймеры, уборка при выключении, хранилище |
| `api.settings` | значения настроек из `settings: [...]` в описании плагина (switch, select, range, color, text) |
| `api.app` | состояние и действия: участники, каналы, история, голос, профиль, уведомления, своя активность, цвет |

## Цвета из аватарки и голос через интернет

`src/palette.js`: картинка скачивается главным процессом (`media:fetch`: только проверенные сайты, переадресации идут вручную и каждая тоже проверяется,
только изображения, до 6 МБ), уменьшается до 64×64 и считается в 4096 цветовых корзинах по оценке «насыщенность × площадь»; чёрный и белый фон не считаются,
серые картинки цвета не дают. Второй цвет берётся не дальше 90° по тону, иначе соседний. В тёмной теме акцент светлее, в светлой темнее.
Голос: `iceServers()` в `voice.js` добавляет публичные STUN только когда адрес комнаты не локальный (частные сети, loopback, Hamachi 25.x, Radmin 26.x, CGNAT, Tailscale); TURN — только свой, из настроек.

## Иконки

`src/icons.js` — 81 своя иконка на сетке 24×24, нарисованных с нуля (ни из каких наборов не взяты). Контур делится на части: `f` — закрытая фигура
(тема может её закрашивать), `s` — линия, `d` — деталь поверх фигуры (глаза, зрачок, кнопки: в плотной теме «вырезается» цветом фона).
Вид задают стили дизайнов: у «Неона» угловые линии со свечением, у «Глины» мягкие линии и двухцветная заливка, у «Экспрессива» сплошные фигуры
с вырезами, у «Стекла» тонкий контур. В тексте иконка вставляется меткой `{{ic:pin}}`: её понимает `Corsa.h()`, в подсказках и полях ввода метка
вырезается. Плагинам доступны `Corsa.icon(имя)` и `Corsa.iconText(строка)`. Тест проверяет корректность каждого пути и что все метки в коде ведут на существующие иконки.
Эмодзи остаются только там, где это содержимое людей: реакции, текст сообщений и системные уведомления Windows.

## Дизайны

«Неон», «Глина», «Экспрессив» и «Стекло» — свои названия и свои цвета. Никаких чужих логотипов, иконок, товарных знаков и
фирменных шрифтов: шрифты Inter, Roboto Flex и Source Serif 4 распространяются по SIL Open Font License (`src/fonts/LICENSE-fonts.txt`).

## Структура

```
main.js, preload.js      главный процесс и мост в интерфейс
server/room-server.js    сервер комнаты (WebSocket, пароль, лимиты, бан)
server/cert.js           самоподписанный сертификат
server/lan.js            поиск комнат в локальной сети
upnp.js                  автоматическое открытие порта на роутере
presence.js              «играет в…» через Discord RPC и список процессов
media.js, media-watch.ps1  «сейчас играет» из системной панели мультимедиа Windows
updater.js               обновление из приложения (GitHub, SHA-256, установка после выхода)
server/files.js          файлы комнаты
shared/                  список проверенных сайтов, код комнаты
src/                     интерфейс (чат, голос, профили, стикеры, плагины, темы)
src/designs.css          дизайны, светлый режим и вид иконок в каждом
src/icons.js             свои иконки (81 штука) и метки {{ic:имя}}
src/palette.js           цвета из картинки (аватарки)
src/builtin/             встроенные плагины
src/fonts/               свободные шрифты (OFL)
examples/                примеры плагина и тем
test/run.js              все проверки
```
