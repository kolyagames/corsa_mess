# corsa-mess

Открытый мессенджер для друзей без центральных серверов: чаты, голос, показ экрана, плагины и темы.
Один из участников нажимает «Запустить сервер», остальные подключаются по коду или по адресу.

## Запуск

```bash
npm install
npm start       # приложение
npm test        # проверки сервера, защиты, стикеров и UPnP
```

Нужен Node.js 20+ (проверено на 24). Приложение: Electron, интерфейс на обычном HTML/JS без сборки.

## Как подключаться

- **Код комнаты** вида `abcdef-ghijk` — это IPv4 и порт, записанные буквами. Сервера-посредника нет.
- **В одной сети** достаточно кода из окна «Запустить сервер».
- **Через интернет**: кнопка «Открыть доступ из интернета» просит роутер открыть порт (UPnP) и показывает код с внешним адресом.
  Работает только с паролем сети. Порт закрывается при остановке сервера.
  Если роутер не поддерживает UPnP или у провайдера общий адрес (CGNAT), используйте Radmin VPN, ZeroTier или Tailscale и подключайтесь по адресу из этой сети.

### Это не VPN как Hamachi

corsa-mess соединяет людей внутри приложения (чат, голос, экран). Он не создаёт виртуальный сетевой адаптер и не передаёт
трафик других программ, поэтому игры по «локальной сети» через него не заработают. Для этого поставьте ZeroTier, Tailscale или Radmin VPN.

## Безопасность

| Угроза | Защита |
|---|---|
| Подслушивание | Весь обмен шифруется (TLS, wss). Сертификат создаётся один раз и хранится в папке данных. |
| Подмена сервера | Отпечаток сертификата запоминается при первом входе. Если изменится — соединение блокируется и показывается предупреждение. |
| Чужие в комнате | Пароль сети. Он не передаётся: сервер шлёт случайный вызов, клиент отвечает HMAC от ключа PBKDF2. Подслушанный ответ повторить нельзя. |
| Подбор пароля | После 5 ошибок адрес блокируется на минуту. |
| Перегрузка | Лимиты: 50 участников, 6 соединений с адреса, 20 сообщений в секунду на соединение, тайм-аут рукопожатия, проверка живости. |
| Самозванцы | Другим участникам показывается не настоящий идентификатор, а его хэш. Права владельца привязаны к настоящему. |
| Нежелательные участники | Владелец может исключить и заблокировать. Адрес 127.0.0.1 не банится. |
| Кража IP через картинки | Ссылки только с проверенных сайтов (`shared/allowlist.js`) и политика CSP: редиректы на чужие адреса блокируются. |
| Взлом через интерфейс | Весь чужой текст попадает на страницу как текст. Песочница, изоляция контекста, запрет навигации и новых окон. |
| Подмена команд | Запросы из интерфейса принимаются только от нашей страницы. Входные данные проверяются. |
| Опасные плагины | По умолчанию выключены. Хэш файлов запоминается при включении: любое изменение отключает плагин. |
| Отладочный порт | Запуск с `--remote-debugging-port` и `--inspect` запрещён. |

**Плагин — это код с полным доступом к интерфейсу.** Включайте только те, которым доверяете.

Ограничения: отпечаток при самом первом входе принимается на веру (как в SSH), поэтому для важных комнат сверяйте его с владельцем
другим способом. Блокировка по адресу не поможет, если у человека динамический адрес.

## Плагины и темы

Откройте папки из Настройки → Плагины и Внешний вид. Тема — `.css` файл, плагин — папка с `manifest.json` и `index.js`.
Примеры лежат в `examples/`. Пример плагина добавляет команду `/dice`.

## Структура

```
main.js, preload.js      главный процесс и мост в интерфейс
server/room-server.js    сервер комнаты (WebSocket, пароль, лимиты, бан)
server/cert.js           самоподписанный сертификат
upnp.js                  автоматическое открытие порта на роутере
presence.js              «играет в…» через Discord RPC и список процессов
shared/                  список проверенных сайтов, код комнаты
src/                     интерфейс (чат, голос, профили, стикеры, плагины, темы)
examples/                примеры плагина и тем
test/run.js              все проверки
```
